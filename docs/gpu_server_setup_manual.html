Ubuntu 24.04.4 LTS Server ASUS ProArt X870E-CREATOR RTX PRO 6000 (48GB) vLLM v0.28.0 + Qwen3.8-27B

GPU 서버 단독 세팅 매뉴얼 (NVIDIA / Docker / vLLM)

집 gpu2 서버(Dual RTX 5070 Ti)에서 실측 검증된 드라이버 및 vLLM 최적화 구성을 바탕으로, 회사의 동일 메인보드 + RTX PRO 6000 단일 48GB GPU 장비에 동일 버전으로 구축하는 표준 가이드입니다.
1

사전 패키지 및 PCIe 장치 점검

Ubuntu 24.04.4 Server 설치 직후, 커널 모듈 빌드(DKMS)와 도구들에 필요한 기본 패키지를 설치합니다.

sudo apt update && sudo apt upgrade -y
sudo apt install -y build-essential dkms curl wget git jq net-tools pciutils

PCIe 슬롯 인식 확인

메인보드 PCIe 5.0/4.0 슬롯에 장착된 RTX PRO 6000 GPU가 정상적으로 버스에 감지되는지 확인합니다:

lspci -nnk | grep -iE 'vga|3d|nvidia'
2

NVIDIA 드라이버 설치 (v580 Open Kernel Module)

Ubuntu 24.04 LTS 공식 리포지토리의 안정화된 nvidia-driver-580-open 버전을 설치합니다. (gpu2에서 구동 중인 580.173.xx와 동일 버전)

# 1. NVIDIA 오픈 커널 모듈 드라이버 설치
sudo apt install -y nvidia-driver-580-open

# 2. Persistence Mode 서비스 활성화 (프로세스 미실행 시에도 드라이버 상주 유지)
sudo systemctl enable --now nvidia-persistenced

# 3. 드라이버 로드를 위한 재부팅
sudo reboot

재부팅 후 드라이버 상태 확인

SSH 재접속 후 GPU 드라이버 정상 인식 상태를 검증합니다:

nvidia-smi
점검 포인트: • Driver Version: 580.173.xx
• Memory-Usage: 49140MiB (48GB VRAM 정상 감지)
• Persistence-M: On
3

Docker Engine 및 Docker Compose 설치

Ubuntu 공식 최신 Docker(29.x) 및 Docker Compose v2 패키지를 설치하고 권한을 부여합니다.

# 1. 패키지 설치
sudo apt install -y docker.io docker-compose-v2

# 2. 현재 사용자 계정을 docker 그룹에 추가
sudo usermod -aG docker $USER

# 3. Docker 서비스 활성화 및 자동 시작
sudo systemctl enable --now docker

# 4. 새 세션 그룹 반영 (터미널 재접속 대체)
newgrp docker
docker --version && docker compose version
4

NVIDIA Container Toolkit 설치 및 Docker 연동

컨테이너 내부에서 호스트 GPU를 접근할 수 있도록 NVIDIA Container Toolkit을 구성합니다.

# 1. GPG 키 등록
curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey | \
  sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg

# 2. APT 저장소 목록 등록
curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list | \
  sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | \
  sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list

# 3. 툴킷 설치
sudo apt update
sudo apt install -y nvidia-container-toolkit

# 4. Docker 런타임 등록 및 데몬 재시작
sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker

GPU 패스스루 스모크 테스트

docker run --rm --gpus all ubuntu nvidia-smi
성공 기준: 컨테이너 안에서 호스트와 동일한 RTX PRO 6000 nvidia-smi 화면이 출력되면 완료입니다.
5

vLLM 컨테이너 구성 및 실행 (Qwen3.8-27B)

RTX PRO 6000 (48GB) 단일 구성 최적화 포인트:
• gpu2(듀얼 5070 Ti 16GBx2)의 경우 1장당 16GB 한계로 인해 TP=2 분할과 엄격한 VRAM 메모리 제한이 필요했습니다.
• RTX PRO 6000은 단일 카드에 48GB VRAM이 탑재되어 있으므로, --tensor-parallel-size 1 단일 GPU 설정으로 프로세스 간 통신 병목 없이 최고 속도를 발휘하며, 최대 16K~32K 컨텍스트와 넉넉한 KV 캐시를 확보할 수 있습니다.

5.1 작업 디렉토리 및 환경 변수(.env) 생성

mkdir -p ~/docker-runtime/vllm
cd ~/docker-runtime/vllm

cat <<'EOF' > ~/docker-runtime/vllm/.env
# Hugging Face 토큰 (필요 시 입력)
HF_TOKEN=

# PyTorch 메모리 파편화 방지 (CUDA Graph 안정화)
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True
EOF

chmod 600 ~/docker-runtime/vllm/.env

5.2 docker-compose.yml 작성

cat <<'EOF' > ~/docker-runtime/vllm/docker-compose.yml
services:
  vllm-qwen:
    image: vllm/vllm-openai:v0.28.0
    container_name: vllm-qwen3.8-27b
    runtime: nvidia
    restart: unless-stopped
    ipc: host
    ports:
      - "8000:8000"
    env_file:
      - .env
    volumes:
      - ~/.cache/huggingface:/root/.cache/huggingface
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: all
              capabilities: [gpu]
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8000/health"]
      interval: 30s
      timeout: 10s
      retries: 30
      start_period: 600s
    command: >
      --model cyankiwi/Qwen3.8-27B-AWQ-INT4
      --served-model-name qwen3.8:27b
      --tensor-parallel-size 1
      --gpu-memory-utilization 0.92
      --max-model-len 16384
      --max-num-seqs 16
      --max-num-batched-tokens 8192
      --kv-cache-dtype fp8
      --enable-chunked-prefill
      --enable-prefix-caching
      --reasoning-parser qwen3
      --port 8000
      --host 0.0.0.0
EOF

5.3 vLLM 기동 및 로그 모니터링

# 백그라운드 기동
docker compose up -d

# 기동 로그 및 모델 로딩 모니터링
docker compose logs -f

로그 마지막에 Uvicorn running on http://0.0.0.0:8000 안내가 나타나면 정상 가동 완료입니다. (로그 종료는 Ctrl + C)

주요 점검 사항 (ASUS ProArt X870E 및 OS)

구분 점검 항목 권장 설정 / 해결책
BIOS Above 4G Decoding Enabled (48GB VRAM 주소 공간 할당 필수)
BIOS Re-Size BAR Support Enabled 또는 Auto
디스크 루트 파티션 LVM 용량 우분투 기본 설치 시 100GB로 제한될 수 있음.
sudo lvextend -l +100%FREE /dev/ubuntu-vg/ubuntu-lv && sudo resize2fs /dev/ubuntu-vg/ubuntu-lv
방화벽 외부 통신 (UFW) 사내 타 PC 연동 필요 시:
sudo ufw allow 8000/tcp
